# Everest Macrocycle Bot — обновление v11.0

## Добавлено

- `/dayplantest` — читает текущий план дня и три заполненных утренних чек-листа.
- Правило допуска онлайн-сессии: `GREEN`, `YELLOW`, `RED`, `INCOMPLETE`, `NO_GAME`.
- Отдельное Telegram-сообщение координатора через устойчивый планировщик.
- Запись теста в `15_Планировщик` и `16_Журнал_действий`.
- Блокировка повторного основного запуска в ту же дату.
- `/dayplantest repeat` для повторного теста после изменения кода или правил.
- `/dayplancleanup CONFIRM` для удаления только тестовых записей этого сценария.

## Не входит в это обновление

- Полное расписание дня.
- Меню и состав приёмов пищи.
- Число игровых столов.
- Автоматическая запись рабочего плана в календарь.

Эти данные бот не придумывает до утверждения соответствующих матриц и правил.

## Запуск теста

1. Заменить `bot.py` и перезапустить сервис.
2. В Telegram отправить `/dayplantest`.
3. Получить техническое подтверждение постановки задания.
4. Через несколько секунд получить отдельное сообщение координатора.
5. Для повторного прогона — `/dayplantest repeat`.
6. После завершения тестов — `/dayplancleanup CONFIRM`.


# Everest Macrocycle Bot — обновление v11.1

## Качество сна в решении по сессии

- Бот читает готовый показатель `Качество сна, 0-10` из `02_День`.
- Показатель обязателен для решения: при отсутствии данных статус `INCOMPLETE`.
- По умолчанию `<= 3,0` даёт `RED`; `3,1–5,4` даёт `YELLOW`; `>= 5,5` не создаёт отдельного ограничения.
- В сообщении координатора отображаются оценка качества сна и её уровень.
- Пороги настраиваются через `SLEEP_QUALITY_RED_MAX` и `SLEEP_QUALITY_YELLOW_MAX`.
- Для текущих данных 30.07.2026 (`4,5/10`) тест выдаёт `YELLOW` и сокращает 6-часовую сессию до 4 часов.


# Everest Macrocycle Bot — обновление v11.2

## Полный план дня

Добавлена команда `/fullplantest`. Она:

1. повторно читает текущее решение `GREEN / YELLOW / RED`;
2. берёт разрешённую продолжительность онлайн-игры;
3. берёт плановый объём работы над игрой из `02_День`;
4. извлекает времена приёмов пищи из последнего шаблона такого же типа дня в `10_План_факт_дня`;
5. сохраняет непрерывность игровых и учебных блоков;
6. при необходимости делит работу над игрой на два блока вокруг еды;
7. сохраняет уже назначенные на сегодня конкретные задачи;
8. добавляет из `05_Проекты_и_задачи` только задачи со статусом допуска `Готово`;
9. отправляет отдельное сообщение координатора через `15_Планировщик`;
10. фиксирует действие в `16_Журнал_действий`.

Для данных 30.07.2026 тестовый результат:

- 06:15 — завтрак;
- 08:30 — второй завтрак;
- 09:00–13:00 — сокращённая онлайн-сессия;
- 11:30 — перекус во время игры;
- 13:00–14:30 — выход из игры и восстановление;
- 13:30 — обед;
- 14:30–16:30 — работа над игрой, блок 1;
- 16:30 — приём пищи;
- 16:50–17:50 — работа над игрой, блок 2;
- 19:00 — ужин.

Новых допущенных задач на текущую дату в таблице нет, поэтому тест не добавляет их искусственно.


# Everest Macrocycle Bot — обновление v12.0

## Блок №26: координатор как manager-agent

Добавлены:

- обработка обычных Telegram-сообщений координатором вместо echo;
- `/hq <поручение>`;
- `/hqtest` для сквозного теста полного дневного ответа;
- `/hqstatus`;
- маршрутизация `BUILD_DAY_PLAN / SESSION_STATUS / MEAL_QUERY / SYSTEM_STATUS / REGISTER_REQUEST`;
- делегирование текущим безопасным адаптерам игры, питания, задач и планировщика;
- единый сводный ответ без технического сообщения о постановке в очередь;
- журналирование каждого запроса через `16_Журнал_действий`;
- защита от повторной обработки одного Telegram message ID;
- необязательная модельная маршрутизация неоднозначных запросов через OpenAI Responses API;
- автоматический переход на строгие локальные правила при отсутствии ключа или ошибке API.

## Границы версии

- агент фаз №27 ещё не подключён;
- агент питания №28 пока возвращает только время приёма пищи, но не меню;
- полноценный покерный агент №29 ещё не подключён;
- планировщик-исполнитель №31 ещё не записывает итоговый план в рабочие вкладки и календарь;
- неподдержанный запрос не имитируется и не меняет рабочие данные.

- тест сборки жёлтого игрового дня — PASS;
- тест вопроса о втором завтраке — PASS;
- тест делегирования четырём адаптерам — PASS.
