# v12.6.0 — отдельный контур Алексея Жукова

## Добавлено

- Независимый Telegram ID Алексея через `ZHUKOV_TELEGRAM_USER_ID`.
- Две персональные кнопки: утренний и постигровой чек-листы.
- Ежедневное расписание в локальном часовом поясе Алексея.
- Проверка таблицы перед напоминанием: уже заполненная форма повторно не присылается.
- Постигровое напоминание пропускается в день отдыха или перелёта по ответу «Сегодня».
- Безопасное получение Telegram ID через `/start` или `/myid`.
- Команды владельца `/zhukovstatus` и `/zhukovtest`.

## Безопасность

- До добавления `ZHUKOV_TELEGRAM_USER_ID` новый контур никому не отправляет сообщения.
- Алексей получает только свои две формы и не имеет доступа к командам владельца.
- Если таблица временно недоступна, вечернее сообщение остаётся условным: в день отдыха ничего заполнять не требуется.
- Токен Telegram и Google-ключи не хранятся в репозитории.

## Не изменено

- Личный утренний и вечерний контур владельца.
- Три существующие утренние формы владельца.
- Отложенное вечернее заполнение владельца.
- AI-координатор и платные вызовы OpenAI API не используются.
