# Hotfix v12.4.1 — 31.07.2026

## Причина

После запуска утреннего обсуждения Google Sheets вернул `429 Quota exceeded for Read requests per minute per user`. В v12.4 одни и те же источники и журнал действий читались отдельными запросами несколько раз подряд.

## Исправления

- три утренних чек-листа читаются одним `values.batchGet`;
- чек-листы вместе с `02_День` читаются одним запросом для фазовой оценки;
- `10_План_факт_дня` и `05_Проекты_и_задачи` читаются одним batch-запросом;
- соединение с Google Sheets переиспользуется в течение жизни контейнера;
- worksheet журнала действий и проверка заголовков кэшируются;
- внутри одного действия журнал читается один раз, повторный полный read-back после append удалён;
- утренний orchestrator читает журнал один раз за tick вместо нескольких;
- добавлен truncated exponential backoff для HTTP 429;
- версия `/hqstatus` изменена на v12.4.1.

## Что не изменилось

- логика трёх утренних форм;
- обсуждение плана дня;
- approval-gate фазового агента;
- чтение `17_Входящие_задачи`;
- запрет автоматического повышения покерной нагрузки.

## Проверки

- `python -m py_compile bot.py` — PASS;
- тест backoff 429 — PASS;
- тест структуры `values.batchGet` — PASS;
- статическая проверка версии и batch-чтений — PASS.

1. `/hqstatus` → v12.4.1, формы 3/3.
2. Подождать 60–90 секунд после старой ошибки 429.
3. `/planningtest` → PASS.
4. `Составь план на день` → начинается обсуждение, а не мгновенная выдача плана.
