# Everest Macrocycle Bot

Закрытый Telegram-бот для системы Macrocycle #3.

## Команды

- `/start` — проверка Telegram-бота и авторизации.
- `/sheet` — проверка доступа к Google Sheets.
- `/readtest` — техническая проверка чтения конкретных рабочих данных из `00_Панель` и `02_День`.
- `/notifytest ЧЧ:ММ` — тестовое уведомление на сегодня по Москве.
- `/buttonstest` — тестовая карточка с кнопками управления.

## Что проверяет `/readtest`

Команда находит сегодняшнюю строку в `02_День` и возвращает:

- текущий мезоцикл и фазу;
- плановый и фактический тип дня;
- ключевую задачу;
- план и факт игры;
- план и факт study;
- общую нагрузку.

Также она читает несколько текущих показателей из `00_Панель`.

На этом этапе команда только читает данные. Она ничего не записывает и не меняет.

## Переменные окружения

- `BOT_TOKEN`
- `TELEGRAM_USER_ID`
- `GOOGLE_SERVICE_ACCOUNT_JSON`
- `GOOGLE_SHEET_ID`
- `PORT` — необязательно, по умолчанию `8000`.
