# Everest Macrocycle Bot v12.6.1

Стабильный контур без AI-координатора и без платных вызовов OpenAI API:

1. Сообщение «Доброе утро» создаёт дневную сессию и фиксирует время старта.
2. Бот выдаёт три утренних Google Forms и проверяет появление ответов.
3. Незаполненный утренний чек-лист напоминается каждые 15 минут.
4. После третьего ответа бот присылает короткий отчёт: дата, фаза, тип дня и рекомендация по покерной нагрузке.
5. Через 15 часов от первого «Доброе утро» бот сначала проверяет вечерний чек-лист.
6. Если вечерней записи нет, бот присылает форму.
7. Вечернее заполнение можно отложить обычным сообщением: `через 2 часа`, `через 45 минут`, `напомни в 22:00`.
8. До отложенного срока 15-минутные напоминания полностью останавливаются.
9. В новый срок бот снова сначала проверяет таблицу. Если ответа нет, присылает форму и возобновляет напоминания каждые 15 минут.
10. После появления записи бот отправляет отчёт закрытия дня и прекращает напоминания.

## Отдельный контур Алексея Жукова

Контур Жукова не меняет личные формы и расписание владельца бота.

1. Алексей нажимает **Start** в существующем Telegram-боте и получает свой Telegram ID.
2. ID добавляется в Railway как `ZHUKOV_TELEGRAM_USER_ID`.
3. Утром Алексей пишет боту `Доброе утро` и сразу получает кнопку утреннего чек-листа.
4. Через 15 часов от отправки утреннего чек-листа бот проверяет ответ «Сегодня».
5. Если указан игровой день и постигровой чек-лист ещё не заполнен, бот присылает его и повторяет напоминание каждые 15 минут.
6. В день отдыха или перелёта постигровые напоминания не отправляются.
7. Состояние отправок записывается в журнал действий и сохраняется после перезапуска Railway.

Переменные Railway:

```text
ZHUKOV_TELEGRAM_USER_ID=<Telegram ID Алексея>
ZHUKOV_TIMEZONE=Asia/Phnom_Penh
ZHUKOV_POSTGAME_DELAY_HOURS=15
ZHUKOV_REMINDER_INTERVAL_MINUTES=15
ZHUKOV_ORCHESTRATOR_TICK_SECONDS=60
ZHUKOV_GOOGLE_SHEET_ID=1Ax_cP0of8ezqL-COJjFBlleHz_Xcle3T1h0vxFrjUmM
ZHUKOV_MORNING_SHEET=Утро — ответы
ZHUKOV_POSTGAME_SHEET=После игры — ответы
```

Ссылки на обе формы уже имеют безопасные значения по умолчанию; при необходимости их можно заменить переменными `ZHUKOV_MORNING_FORM_URL` и `ZHUKOV_POSTGAME_FORM_URL`.

Чтобы бот видел ответы, таблицу Жукова нужно открыть для адреса `client_email` из действующей переменной `GOOGLE_SERVICE_ACCOUNT_JSON` в роли читателя.

## Вечерняя форма

URL уже встроен как безопасное значение по умолчанию:

`https://docs.google.com/forms/d/e/1FAIpQLSdZ4s4fsLyqxAgdLrxVKV72UQEQOcIrq1gjD1uj59L0wnxFzw/viewform`

Необязательные Railway Variables:

```text
EVENING_FORM_URL=<другая ссылка, если форма изменится>
EVENING_SHEET=Вечер
EVENING_DELAY_HOURS=15
EVENING_REMINDER_INTERVAL_MINUTES=15
EVENING_RESPONSE_RANGE=A1:AZ1000
EVENING_SNOOZE_MIN_MINUTES=5
EVENING_SNOOZE_MAX_HOURS=24
```

`EVENING_SHEET` должен совпадать с названием вкладки ответов формы. По умолчанию бот ищет `Вечер`; если точного листа нет, он безопасно ищет вкладку, в названии которой есть слово «вечер».

## Примеры переноса

После первого вечернего уведомления можно написать:

```text
через 2 часа
Заполню через полтора часа
напомни через 45 минут
напомни в 22:00
```

Перенос хранится в `16_Журнал_действий`, поэтому переживает перезапуск Railway. Повторный перенос заменяет предыдущий новым сроком.

## Команды

- `/hqstatus` — общий статус.
- `/morningstatus` — состояние трёх утренних чек-листов.
- `/morningcheck` — немедленная проверка утра.
- `/morningtest` — ускоренный изолированный тест утреннего сценария.
- `/eveningstatus` — срок и состояние вечернего чек-листа, включая перенос.
- `/eveningcheck` — немедленная проверка вечернего контура.
- `/eveningtest` — проверка URL, интервалов, распознавания переноса и доступа к вкладке ответов без изменения данных.
- `/myid` — показать Telegram ID отправителя; подходит для безопасного подключения Алексея.
- `/forms` — показать две ссылки Жукова ему самому или владельцу бота.
- `/zhukovstatus` — статус подключения, расписания и таблицы Жукова; доступен владельцу.
- `/zhukovtest` — отправить Алексею тестовое сообщение с двумя кнопками; доступен владельцу.

## Обновление

Заменить корневой `bot.py` в GitHub и сделать commit. Railway автоматически создаст новый deployment.

После успешного deployment:

```text
/hqstatus
/eveningtest
/zhukovstatus
```

Ожидаемая версия: `v12.6.1`.
