# Everest Macrocycle Bot

Закрытый Telegram-бот для системы Macrocycle #3.

## Команды

- `/start` — проверка Telegram-бота и авторизации.
- `/sheet` — проверка доступа к Google Sheets.
- `/readtest` — чтение конкретных рабочих данных из `00_Панель` и `02_День`.
- `/writetest` — безопасный тест записи в `10_План_факт_дня`.
- `/notifytest ЧЧ:ММ` — тестовое уведомление на сегодня по Москве.
- `/buttonstest` — тестовая карточка с кнопками управления.

## Что проверяет `/writetest`

Команда использует зарезервированную ячейку `10_План_факт_дня!R504`:

1. убеждается, что ячейка свободна;
2. записывает уникальную техническую метку;
3. читает её обратно;
4. сверяет формулы строки до и после записи;
5. удаляет тестовую метку;
6. повторно проверяет очистку и целостность формул.

Рабочий план, факт и показатели дня не изменяются.

## Переменные окружения

- `BOT_TOKEN`
- `TELEGRAM_USER_ID`
- `GOOGLE_SERVICE_ACCOUNT_JSON`
- `GOOGLE_SHEET_ID`
- `PORT` — необязательно, по умолчанию `8000`.
