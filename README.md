# Everest Macrocycle Bot

Закрытый Telegram-бот для системы Macrocycle #3.

## Команды

- `/start` — проверка Telegram-бота и авторизации.
- `/sheet` — проверка доступа к Google Sheets.
- `/readtest` — чтение рабочих данных.
- `/writetest` — безопасный тест записи в план-факт.
- `/calendartest` — чтение Google Calendar и поиск пересечений.
- `/eventtest` — создание, изменение и удаление тестового события.
- `/notifytest ЧЧ:ММ` — старый тест уведомления в памяти процесса.
- `/schedulertest ЧЧ:ММ` — устойчивое плановое задание с хранением в Google Sheets.
- `/schedulerstatus` — последние задания и их статусы.
- `/buttonstest` — тестовая карточка с кнопками.

## Блок №24: устойчивый планировщик

При первом запуске бот автоматически создаёт вкладку `15_Планировщик`.

Хранятся:

- уникальный `SCHED_ID`;
- тип задания;
- статус;
- плановое время и часовой пояс;
- Telegram chat ID и текст;
- `DEDUP_KEY`;
- время создания и отправки;
- число попыток, ошибка, источник и системная проверка.

### Защита от дублей

Одинаковое задание определяется по типу, чату, времени и тексту. Повторная команда не создаёт вторую строку и не ставит вторую доставку.

### Восстановление после Railway

При каждом запуске бот читает строки со статусом `SCHEDULED` и заново ставит будущие задания в очередь.

Если Railway запустился в течение 15 минут после планового времени, задание доставляется с короткой задержкой. Более старые задания получают статус `EXPIRED`.

### Защита от повторной отправки

Перед отправкой строка переводится из `SCHEDULED` в `DELIVERING`. После успешной доставки — в `SENT`. Зависшее состояние `DELIVERING` автоматически не пересылается повторно: оно помечается как ошибка, чтобы исключить дубль.

### Тест

1. Выполнить `/schedulertest ЧЧ:ММ` на 8–10 минут вперёд.
2. Повторить ту же команду — бот должен заблокировать дубль.
3. Перезапустить Railway до назначенного времени.
4. Дождаться сообщения.
5. Выполнить `/schedulerstatus` — строка должна иметь статус `SENT`.

## Переменные окружения

- `BOT_TOKEN`
- `TELEGRAM_USER_ID`
- `GOOGLE_SERVICE_ACCOUNT_JSON`
- `GOOGLE_SHEET_ID`
- `GOOGLE_CALENDAR_ID` — необязательно; по умолчанию `azalcyprus@gmail.com`.
- `PORT` — необязательно, по умолчанию `8000`.
