# Everest Macrocycle Bot

Закрытый Telegram-бот для системы Macrocycle #3.

## Команды

- `/start` — проверка Telegram-бота и авторизации.
- `/sheet` — проверка доступа к Google Sheets.
- `/readtest` — чтение рабочих данных из `00_Панель` и `02_День`.
- `/writetest` — безопасный тест записи в `10_План_факт_дня`.
- `/calendartest` — чтение Google Calendar на 7 дней и поиск пересечений.
- `/calendartest 14` — то же на 14 дней; допустимо от 1 до 30 дней.
- `/eventtest` — создание, чтение, изменение и удаление изолированного тестового события.
- `/notifytest ЧЧ:ММ` — тестовое уведомление на сегодня по Москве.
- `/buttonstest` — тестовая карточка с кнопками управления.

## Что проверяет `/eventtest`

Команда автоматически:

1. создаёт прозрачное тестовое событие без напоминаний и приглашений;
2. читает его обратно и сверяет ID, название, время и техническую метку;
3. проверяет, что существует ровно один экземпляр;
4. изменяет название, время начала и длительность;
5. повторно читает событие и проверяет изменения;
6. удаляет событие;
7. убеждается, что оно больше недоступно и дублей не осталось.

Событие существует только несколько секунд. Реальные события календаря не изменяются. При ошибке код пытается выполнить аварийную очистку.

## Переменные окружения

- `BOT_TOKEN`
- `TELEGRAM_USER_ID`
- `GOOGLE_SERVICE_ACCOUNT_JSON`
- `GOOGLE_SHEET_ID`
- `GOOGLE_CALENDAR_ID` — необязательно; по умолчанию `azalcyprus@gmail.com`.
- `PORT` — необязательно, по умолчанию `8000`.

## Исправление v8.1

Google Calendar после удаления иногда возвращает событие через `events.get` со статусом `cancelled`, а не ошибку 404/410. Теперь тест корректно принимает оба варианта удаления и дополнительно проверяет, что активных событий с тестовой меткой не осталось.
