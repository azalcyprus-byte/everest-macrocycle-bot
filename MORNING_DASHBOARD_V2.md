## Поля плана

Существующие A:I сохранены. Дополнительные поля:

- J: `Анализ трансляций (мин)`.
- K: `Видеоразборы (мин)`.
- L: `Физическая активность (мин)`.
- M: `Часовой пояс`, при необходимости явный IANA zone, например `Asia/Phnom_Penh`.

Игра читается из `Game OPT (ч)`, без подстановки MIN/MAX. Пустые клетки
не равны нулю. Физическая активность без плана отмечается как самоконтроль.
Даты заполнены только для заданного периода; нагрузки тренер вносит сам.
Конфликтующие дубли дат не используются. Первый цикл не подмешивается в план.

## Расчёты и пропуски

- Историческая формула индекса S+Z+V+C сохранена. Нумерация вопроса о
  пробуждении нормализована (`1.` в реальной форме / `2.` в старом коде).
  Неполная анкета не отображается как индекс 0. Индекс не является точной
  оценкой игровой готовности.
- Сон = локальное окончательное пробуждение минус UTC-момент нажатия
  кнопки сна минус согласованная задержка засыпания. Категории согласованы
  с тренером 21.11.2026: до 15 мин → 7,5; 15–30 → 22,5; 30–60 → 45.
  Для «более часа», отсутствующей кнопки или неизвестного часового пояса —
  «Нет данных». Время ночного бодрствования неизвестно и не вычитается.
- Локальная дата из анкеты — дата отчёта. Момент отправки интерпретируется
  в часовом поясе исходной таблицы. В новой вечерней форме `en_US` slash-даты
  читаются как MM/DD/YYYY. Для сна приоритет у M в плане, затем у известного
  города анкеты; для пустого города — `ZHUKOV_TIMEZONE`. Неизвестный указанный
  город не превращается автоматически в другой часовой пояс.
- 72 часа — три завершённых календарных дня D−3…D−1, не скользящие часы
  от момента отправки. Сон — ночи, завершившиеся утром D−2, D−1 и D.
- При неполном покрытии показываются сумма известных значений и `n/3`.
  Если значений нет, показывается «Нет данных». Суммы не являются общим
  баллом усталости. Ответ «игрового дня не было» — подтверждённый игровой 0;
  пустые минуты обучения/физической активности остаются неизвестными.
- График содержит ровно 7 календарных дней; пропуски разрывают линию.

## Доставка и восстановление

`Everest_Алексей_утро_v2` хранит дату, chat ID, message ID, хеш изображения
и статус. Изменение данных приводит к `edit_message_media` по сохранённому ID.
Статус SENDING резервируется до отправки. Неоднозначный timeout отправки
помечается REVIEW и не вызывает повторной отправки. Удалённое пользователем
сообщение также требует разбора, чтобы не создавать автоматический дубль.

При первой установке не рассылаются старые даты; текущий день допустим.
Ручной пересчёт: `/zhukovmorning 26.11.2026` — обновляет сообщение тренеру,
а не создаёт отдельную копию. Периодическая проверка — существующий интервал
мониторинга 5 минут. При отсутствии анкеты PNG не отправляется.

## Проверки

`python -m unittest discover -s tests -p 'test_zhukov_*.py'`

Проверяются учебный, игровой и отдых/перелёт, неполная анкета, пропуск
кнопки, отсутствие плана, реальные заголовки форм, 72-часовые границы,
US-даты, отсутствие старого источника и повторная доставка/редактирование.
`tools/preview_morning_dashboard.py <папка>` создаёт только локальные
PNG с явной маркировкой тестовых данных, без сообщений Telegram.

Шрифт Noto Sans поставляется с лицензией SIL OFL в `assets/`.
